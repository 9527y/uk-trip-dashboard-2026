# UK Tripboard 2026

一页式英国旅行面板。最新版行程于 2026-09-28 同步：Barmy Badger 伦敦 5 晚、剑桥与七姐妹白崖当天往返、Castle Rock 爱丁堡 3 晚，两家青旅均已预订。

线上地址：https://9527y.github.io/uk-trip-dashboard-2026/

## 行程范围

- 9/28 23:05 香港出发，9/29 07:55 抵达伦敦。
- 9/29–10/4 住伦敦：9/30 西区、10/1 剑桥、10/2 大英博物馆、10/3 白崖短线。
- 10/4 北上爱丁堡。已公布铁路施工及 Carlisle 绕行，整天留给交通。
- 10/4–10/7 住爱丁堡：10/5 老城、10/6 山景与博物馆。
- 10/7 12:50 从爱丁堡返程，10/8 15:20 抵达香港。

剑桥和白崖分别从伦敦往返。白崖按天气调整，换日后同步核对景点预约及车票。所有列车默认时间都是查询建议，未代表已购票或已确认的班次。

## 页面内容

- 当前阶段、航班倒计时、准备清单和穿衣建议
- 已订青旅的日期、官网地址、导航和到达提醒；截图未含的房型、费用与订单条款待补充
- 景点、车站、上车点与青旅的中英名称；每日地点保留可复制的英文地图搜索词
- 伦敦散步地名速查，区分伦敦桥／塔桥、骑兵入口／阅兵场等容易混淆的目的地
- 总览／伦敦周边／白崖三个地图视图及导航
- 两次日游往返和一次北上共五段列车卡片，可编辑票面时间
- 白崖公交方向、上车点、徒步短线和机场接驳
- 每日步骤、当晚青旅及沿路餐饮，附住宿导航和官方菜单入口；10/7 返程不再安排青旅住宿
- 9/29–10/2 顺路影视打卡：破釜酒吧门面、皮卡迪利广场、国王十字 9¾ 推车点与 BBC 夏洛克公寓外景，直接嵌入当天顺序
- 当地开支预算与可编辑汇率；金额为预算，非实时报价

数据来自 `lib/itinerary.ts`、`lib/trip-plan.ts`、`lib/stays.ts`；核验来源见 `docs/`。待办和已编辑车次只保存在当前浏览器，不跨设备同步。

新版只迁移旧清单中仍适用的待办。9/20 两项已核实住宿使用新任务 ID，初始标为完成，避免旧的未完成值覆盖已订记录；其他清单勾选和之后的手动修改照常保留。旧路线车次与预约不会自动标为完成；两次日游的去回程各共用一个往返购票状态。

推送到 `main` 后，GitHub Actions 构建并发布到现有 GitHub Pages。项目以 `uk-trip-dashboard-2026` 为路径前缀；仓库改名时同步修改 `next.config.ts` 的 `assetPrefix`。
